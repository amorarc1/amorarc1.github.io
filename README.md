# amorarc.github.io

## Créditos y Recursos de Terceros

Este proyecto utiliza modelos 3D y texturas de dominio público (Licencia CC0) obtenidos de las siguientes plataformas:

* **[ambientCG](https://ambientcg.com/):** Texturas generales de entorno y materiales PBR.
* **[TextureCan](https://www.texturecan.com/):** Texturas específicas (incluyendo [Apple Skin Texture](https://www.texturecan.com/details/185/)).

Todos los recursos externos se han utilizado de acuerdo con sus respectivas licencias abiertas.
